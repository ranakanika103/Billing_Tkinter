# 🧾 Supermarket Billing System

A feature-rich, user-friendly desktop billing application built using **Python Tkinter** and **SQLite**. This GUI software is ideal for small to medium-sized supermarkets, retail shops, or general stores. It enables you to handle customer purchases, generate detailed itemized bills with tax calculations, and save or retrieve bills with ease.

---

## 🚀 Features

- 🧍‍♂️ Customer Info: Name & Contact entry
- 📦 Product Selection: Category → Subcategory → Product
- 🧮 Auto Price & Quantity input
- 🧾 Bill generation with proper formatting
- 🏦 5% tax calculation
- 💾 Save bills to local SQLite database
- 🔍 Search previous bills by Bill No
- 🖥️ Clean and intuitive Tkinter GUI
